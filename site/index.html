Lor GitHub

SSH access for AI agents that ends on time

Lor is a small SSH certificate authority for your homelab. An agent asks for access, you approve it with a passkey tap on your phone, and the certificate expires on its own. No standing keys left behind.

  • Short-lived certificates
  • Passkey approvals
  • Every command shown
  • One static binary

Install

One line each. Both fetch the latest release from GitHub and check its SHA-256.

Agent CLI

On the machine your agent runs on · Linux and macOS

Install lor
$ curl -fsSL https://lor.hyperf.app/install.sh | sh
Then enroll
$ lor enroll --url … --fingerprint … --code …

Copy the exact command from Agents → Add agent in your Lor. Add -s -- --skill after sh to also install the Claude Code skill.

Lor server

On its own small LXC or VM · Linux with systemd

Install lor-server
$ curl -fsSL https://lor.hyperf.app/install.sh | sudo sh -s -- --server

Installs the binary, a lor system user, an example /etc/lor/lor-server.toml and the systemd unit. Edit the config, then systemctl enable --now lor-server. Running it again upgrades in place. The deployment guide covers Caddy and passkey setup.

Like to look first? Read install.sh, or grab the archives and SHA256SUMS from GitHub Releases. Pin a version with sh -s -- --version v0.1.0.

How it works

Access is a short-lived OpenSSH certificate, so hosts enforce the end time even if Lor is down.

  1. 1

    The agent asks

    lor request nas --for 1h --reason "…" prints an approval link for the agent to share with you in chat.

  2. 2

    You approve

    Open the link on your phone, see exactly what would be allowed, and confirm with your passkey.

  3. 3

    It expires

    The agent runs lor ssh nas -- … until the certificate ends. Extend or revoke any time.
